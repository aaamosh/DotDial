# DotDial share media

## Linux beta and macOS preview

- [Current platform share card](dotdial-platforms-card.png): 1200 × 630 PNG.
- [Editable platform card](dotdial-platforms-card.svg): SVG with the same layout.

This card announces the Linux x86_64 beta and [macOS Preview 1 for Apple Silicon and Intel](https://github.com/aaamosh/DotDial/releases/tag/v0.1.0-beta.3-macos-preview.1). It uses original typography and the existing DotDial icon; it is a promotional graphic, with no application screenshot or live-call image. It identifies the Mac preview as ad-hoc signed, not notarized, and awaiting hands-on Mac testing. Keep the preview status, signing note and existing-dot requirement visible when sharing.

The card's layout and project icon are covered by the [MIT License](../../LICENSE). The icon is from the [ce7c1998 project source](https://github.com/aaamosh/DotDial/blob/ce7c19980976aa1719d2a4c156b377b4c9ac0a7b/src/assets/dotdial.svg). macOS availability was verified against the release built from [54889c5b](https://github.com/aaamosh/DotDial/commit/54889c5b04fe3dc32b79084d56bbec6e187a53de).

**Platform-card alt text:** Dark navy and mint DotDial card headed "Linux beta · macOS preview" and "Your dot. One shortcut away." macOS Preview 1 provides Apple Silicon and Intel DMG/app ZIP downloads and the Command–Shift–Space shortcut. Features include optional local English "Hey Dot" recognition, off by default; saved replies with optional local recording; and a real 1997 modem handshake. A footnote says the Mac preview is ad-hoc signed, not notarized, and awaiting hands-on Mac testing. The card identifies the project as MIT, unofficial, and requiring existing ChatGPT dot access. No screenshot or live call is shown.
