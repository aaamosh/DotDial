# DotDial share media

- [Share card](dotdial-social-card.png): 1200 × 630 PNG.
- [Preview video](dotdial-preview-18s.mp4): 18 seconds, 1280 × 720, H.264/AAC, MP4 faststart.

These are compositions of the project's existing **synthetic UI screenshots**, not a live-call recording. Keep the synthetic-preview label visible. Every composition identifies the Linux x86_64 beta, unofficial status and existing ChatGPT dot requirement.

## Sources and rights

The visuals use the original [panel](../images/panel.png), [settings](../images/settings.png), [voice](../images/voice.png) screenshots and [DotDial icon](../../src/assets/dotdial.svg). They have been proportionally scaled and placed in a new layout. Project material is covered by the [MIT License](../../LICENSE).

Audio: **Ektoras Karagiannis, 1997**, a 14.4 kbps modem handshake, [CC0 source](https://archive.org/details/14400_201912). See [third-party notices](../../THIRD_PARTY_NOTICES.md). The video uses the first 18 seconds, gain 0.32, a 0.2-second fade-in and a 1.2-second fade-out. It is illustrative audio under a synthetic preview.

## Alt text

**Share card:** Dark navy and mint DotDial card with the headline “Say ‘Hey Dot.’ Call hands free.” The project's synthetic Voice settings screenshot appears alongside local wake-word, saved-reply and modem-sound features. Labels state Linux x86_64 beta, MIT, unofficial project and existing ChatGPT dot required.

**Video:** Three scenes introduce voice calling, locally saved replies and the 1997 modem sound using existing synthetic screenshots. The final scene includes the repository URL and sound credit. No real account or conversation is shown.
